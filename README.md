# Revizio PWA

Aplicație Progressive Web App (PWA) modernă, responsive și orientată pe mobil pentru gestionarea reviziilor și verificărilor de instalații de gaze naturale.

## Tehnologii Folosite
- HTML5, CSS3 Modern (Grid/Flexbox, CSS Variables, Suport Dark/Light Mode)
- JavaScript ES6+ Modular
- PWA (Web Manifest, Service Worker pentru funcționare Offline, Iconițe dedicate)
- LocalStorage pentru persistența datelor fără backend obligatoriu

## Rulare și Publicare pe GitHub Pages
1. Dezarhivează proiectul și urcă toate fișierele într-un repository nou pe GitHub.
2. Mergi la **Settings > Pages** în repository-ul tău.
3. La secțiunea **Build and deployment**, setează sursa la **Deploy from a branch** (Branch: `main` / `/ (root)`).
4. După câteva secunde, aplicația va fi publicată și accesibilă online.

## Instalare ca PWA
Poți instala aplicația direct pe telefonul mobil (Android / iOS) sau pe PC folosind opțiunea „Add to Home Screen” / „Instalează aplicația” din browser.
